# Java Method Drawer

프로그래머스 문제를 풀며 배운 Java 메소드와 예제를 카드 형태로 정리하는 개인 학습용 웹사이트입니다.

## 주요 기능

- Java 메소드와 개념을 카테고리별로 정리
- 메소드 이름과 내용 검색
- 새로운 카드 추가
- 카드 삭제 및 전체 초기화
- 브라우저 `localStorage`를 이용한 데이터 저장

## 카테고리

입출력, 문자/아스키, 문자열, StringBuilder, 제어문, 형변환, 자료구조, 배열, Math, Stream, 날짜/시간, 개념

## 사용 방법

`index.html`을 브라우저에서 열거나 GitHub Pages 배포 주소로 접속합니다.

> 새로 추가한 카드는 현재 사용 중인 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지는 않습니다.

## 만든 목적

코딩 문제를 풀면서 새롭게 알게 된 Java 메소드와 사용 예시를 한곳에 기록하고 반복해서 복습하기 위해 만들었습니다.
