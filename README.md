# Java Method Drawer

프로그래머스 **기초 문제를 모두 풀고 입문 문제를 푸는 단계**에서 배운 Java 메소드와 예제를 카드 형태로 정리하는 개인 학습용 웹사이트입니다.

## 현재 프로젝트 분석

- 카드 데이터는 충실하지만 학습 수준과 추천 사용 순서가 화면에 드러나지 않아 처음 방문하면 용도를 파악하기 어려웠습니다.
- 검색이 이름과 설명만 대상으로 삼아, 예제 코드나 카테고리에서 본 키워드로는 카드를 찾을 수 없었습니다.
- 모바일에서 카테고리 버튼이 여러 줄을 차지하고 긴 코드가 강제로 줄바꿈되어 코드를 읽기 어려웠습니다.
- 예제를 다시 입력해야 해서 직접 실행하며 학습하기 번거로웠습니다.
- 모든 카드에 같은 학습 팁이 반복되고, 긴 카드 본문은 고정된 최대 높이 때문에 잘릴 수 있었습니다.
- 기존 광고 영역은 자리만 있다는 점이 사용자에게 충분히 명확하지 않았습니다.

이번 개선은 위 문제를 해결하되 기존 기본 카드와 브라우저에 저장된 사용자 카드를 삭제하거나 덮어쓰지 않는 방향으로 진행했습니다.

## 주요 기능

- Java 메소드와 개념을 카테고리별로 정리
- 메소드 이름과 내용 검색
- 예제 코드 복사와 입문 학습 팁
- 새로운 카드 추가
- 카드 삭제, 기본값 초기화, JSON 백업/복원
- 브라우저 `localStorage`를 이용한 데이터 저장
- 모바일 반응형 UI와 키보드/스크린 리더 접근성

## 카테고리

입출력, 문자/아스키, 문자열, StringBuilder, 제어문, 형변환, 자료구조, 배열, Math, Stream, 날짜/시간, 개념

## 사용 방법

`index.html`을 브라우저에서 열거나 GitHub Pages 배포 주소로 접속합니다.

> 새로 추가한 카드는 현재 사용 중인 브라우저에 저장됩니다. 다른 기기와 자동으로 동기화되지는 않습니다.

## 만든 목적

코딩 문제를 풀면서 새롭게 알게 된 Java 메소드와 사용 예시를 한곳에 기록하고 반복해서 복습하기 위해 만들었습니다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다. 별도의 빌드 과정이나 패키지 설치는 필요하지 않습니다.

## 광고 수익화 준비

화면 하단에는 콘텐츠를 가리지 않는 광고 슬롯이 준비되어 있습니다. 실제 광고를 붙이기 전에는 다음 순서를 권장합니다.

1. GitHub Pages에 배포하고 커스텀 도메인과 HTTPS를 연결합니다.
2. Java 예제의 정확성을 검수하고 검색 유입을 받을 수 있는 독창적인 설명을 꾸준히 추가합니다.
3. 운영자 정보, 개인정보처리방침, 문의 방법을 별도 페이지로 제공합니다.
4. Google AdSense 등 광고 플랫폼의 심사를 받은 뒤 발급된 게시자 스크립트와 광고 단위를 `.ad-slot` 위치에 연결합니다.
5. 쿠키나 개인화 광고를 사용한다면 방문 지역에 맞는 동의 관리 플랫폼(CMP)을 적용합니다.
6. 광고 클릭을 유도하는 문구를 쓰거나 콘텐츠보다 광고를 과도하게 배치하지 않습니다.

> 저장소에는 게시자 ID나 가짜 광고 코드를 넣지 않았습니다. 광고 계정 승인 후 본인의 값으로 연결해야 합니다.

## 출시 전 체크리스트

- `title`과 설명 메타 태그를 실제 서비스명에 맞게 유지
- 잘못된 Java 설명과 실행 예제가 없는지 검수
- 실제 도메인 기준 `robots.txt`, `sitemap.xml`, canonical URL 추가
- 개인정보처리방침·문의 페이지와 푸터 링크 추가
- Lighthouse로 성능·접근성·SEO 점검
- Search Console 및 개인정보 친화적인 분석 도구 연결
